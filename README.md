# 🎯 Number Guessing Game (Python)

A beginner-friendly command-line number guessing game built with Python. The program generates a random number, and the player must guess it using the hints provided.

## ✨ Features

- 🎲 Random number generation
- 📈 Hint system ("Higher" or "Lower")
- 🔢 Unlimited guesses
- 📊 Counts the total number of attempts
- 🔄 Replay option

## 📂 Technologies Used

- Python 3
- random module

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/Number-Guessing-Game-Python.git
```

2. Open the project folder:

```bash
cd Number-Guessing-Game-Python
```

3. Run the program:

```bash
python number_guessing_game.py
```
